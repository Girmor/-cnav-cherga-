# ЦНАВ · Електронна черга

Жартівливе табло «черги на питання» для планшета: LED-табло з номером, електронні талони для колег, пульт для оператора, статус вікна, денний ліміт питань і лічильник «днів без „а є хвилинка?“».

Статичний сайт без збірки. На Netlify публікується як є (`netlify.toml` вже налаштований).

| файл | хто дивиться | що це |
|---|---|---|
| `index.html` | усі | табло на планшеті + QR «Взяти талон» |
| `talon.html` | колеги | електронний талон на їхньому телефоні (QR з табло) |
| `remote.html` | ви | пульт оператора (QR у ⚙ → «Пульт з телефона») |
| `common.js` | — | спільний код: LED-цифри, QR, зв’язок |

## Як користуватись
**Оператор (ви).** Планшет: відкрити сайт → «Поділитися» → «На початковий екран». Щоранку — «Відкрити вікно» (цей дотик вмикає звук на iPad). Пульт: «📱 Підключити пульт» → відсканувати QR телефоном. Далі все з пульта: «Наступний», статус, ліміт, «Спитали», список черги з суттю питань і табличка в шапці табло (свій текст на кшталт «Поїхав на Мадейру… буду у 2027» або готові варіанти).

**Колеги.** Сканують QR «Взяти талон» на табло → обирають послугу (⚡ швидке, 👀 «просто глянь», 🧠 складне, 🍫 з шоколадним фонданом — без черги) → отримують талон і бачать, скільки перед ними. Коли черга підходить — телефон дзенькає і показує «ВАША ЧЕРГА!». Після — оцінка зірочками (рейтинг видно на табло). Розібралися самі — медаль.

## Як це працює
Табло, пульт і талони спілкуються через безкоштовні публічні MQTT-брокери (shiftr.io, HiveMQ, EMQX — одразу через усі, щоб пережити падіння одного). У пульта і відвідувачів різні коди: з талона табло не покеруєш. Через сервери ходять лише номери, статус, лічильники і короткий текст «суті питання» — нічого секретного туди не пишіть. «Новий код» у вікні пульта відключає всі старі пульти.

Стан зберігається в браузері планшета. Ліміт, черга і рейтинг скидаються щодня о 10:00.

Клавіатура на табло: `→`/пробіл — наступний, `←` — назад, `+`/`-` — питання, `1`/`2`/`3` — статус.
